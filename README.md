# 诗墨山河 · 古风诗词小游戏（可运行 Demo）

> 择一位诗人作“诗魂”，以你的心事为引，按他的风格生成新诗；闯诗关赚“诗墨”积分，兑换重工非遗徽章。
> 纯静态前端（Phaser 2D 场景层 + DOM HUD），**无构建依赖**，双击即可运行。

---

## 一、运行方式

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| A（推荐） | 双击 `start.bat` | 自动起本地服务并打开 `http://localhost:8123/` |
| B | 直接双击 `index.html` | 无 fetch / 无 ES Module，图片与脚本走相对路径，多数浏览器可直接运行 |
| C | 任意静态服务器托管本目录 | 例：`server.ps1`（内置，纯 PowerShell TCP 实现，无需 Node/Python） |

> 本机已验证：无 Node / 无 Python 环境，故方案完全自包含。Phaser 3.80 已本地化到 `vendor/phaser.min.js`。

## 二、玩法设计

### 2.1 核心循环

| # | 玩家动作 | 系统反馈 | 数值 |
| --- | --- | --- | --- |
| 1 | 择诗魂（5 位诗人卡片） | 该诗人风格词库即刻生效，NPC 开场白 | — |
| 2 | 赋诗：写下心事 + 选五言/七言 | 生成四句新诗，附题记、韵脚、意象、信物与 NPC 评语 | — |
| 3 | 收进诗集 | 写入本地存档 | 上限 30 首 |
| 4 | 闯诗关：选题材 → 6 题 | 三种题型轮换，15 秒限时，连击加成 | 基础 +6，连击 +1/级（≤5 级），时间 ≤+3 |
| 5 | 兑换徽章 | 扣诗墨、解锁，弹出重工徽章详情 | 160 / 160 / 220 / 300 / 300 诗墨 |
| 6 | 徽章鉴赏 | 展示非遗工艺、取用元素、配色与典故 | — |

一次完整会话约 3–6 分钟，可随时中断（进度存 localStorage）。

### 2.2 四大模块

1. **择诗魂**：李白·谪仙风 / 杜甫·沉郁风 / 王维·禅意风 / 李清照·婉约风 / 苏轼·旷达风。每位诗人 = 一套词库 + 一件与其生平高度相关的非遗徽章 + 一组对谈台词。
2. **赋诗阁**：输入任意文本（≤60 字），选体裁，点「请君赋诗」；输出竖排诗文 + 朱砂印章 + 创作参数（韵脚/意象/信物）+ NPC 评语。支持「再来一首」「收进诗集」，`Ctrl/Cmd + Enter` 快捷赋诗。
3. **闯诗关**：8 个题材（明月 / 送别 / 边塞 / 山水 / 相思 / 豪放 / 田园 / 咏物），题库由诗词库实时生成。三种题型：
   - **诗句接续**：给上句，从 4 个下句中择一（干扰项同字数）
   - **名句识人**：给名句，从 4 位作者中择一
   - **补字填空**：挖去名句中间一字，从 4 个字中择一
   段位：诗仙（全对）/ 诗豪（≥80%）/ 诗客（≥60%）/ 学童（≥40%）/ 初执笔。
4. **徽章阁**：5 枚珐琅重工徽章，未得者置灰显示所需价位，积分足够即可兑换；点击任意徽章打开详情（非遗工艺 + 取用元素 + 配色 + 缘起典故 + 诗人原句）。

### 2.3 美术与音乐方向

- **画面**：彩色水墨（青绿 + 朱砂 + 米黄宣纸），背景为水墨山水长卷；卡片走“宣纸 + 朱砂细边”材质语言；诗文竖排右起。
- **动效**：场景层为落花、流云、飞鸟、墨点；角色立绘做呼吸式浮动（选中诗魂后节奏加快）；空白处点击溅出墨花。全部遵循 `prefers-reduced-motion`。
- **音乐**：Web Audio 程序化合成，五声音阶（宫商角徵羽）古琴拨弦音色 + 反馈延时混响 + 每 8 拍低音散音，无需任何音频文件。

## 三、诗词生成：双引擎（`js/systems/generator.js` + `js/systems/llm.js`）

赋诗支持两种引擎，可在界面右上角 `✦` 一键切换；**大模型未配置、超时或返回不合规时，自动回退本地词库**，游戏永远可用。

### 3.1 大模型引擎（已接入，`llm.js`）

- **协议**：OpenAI 兼容 `POST /chat/completions`，浏览器直连官方接口（支持 CORS）。
- **预置服务商**：DeepSeek（`deepseek-chat`）/ 通义千问（`qwen-plus`）/ Kimi（`moonshot-v1-8k`）/ 智谱 GLM（`glm-4-flash`，有免费额度）/ 自定义接口。
- **配置**：顶栏 `✦` 打开设置弹层 → 选服务商、粘 API Key、勾选启用 → 「测试连接」验证 → 保存。密钥只存本机 `localStorage`（键 `poem-ink-llm-v1`），不上传任何服务器，重置存档不会清除。
- **Prompt 策略**：system 注入诗人完整人设（朝代、字号、风格名、风格标签、生平、随身旧物、惯用意象词库）+ 严格输出约束（四句、每句恰 5/7 字、二四句押韵、JSON 结构 `{title, lines[4], comment}`）。
- **校验与容错**：提取首尾 `{}` 内 JSON → 剥标点 → 校验 4 句 × 每句字数（兼容“两句逗号合并”拆句）→ 任一不合规即抛错，由 HUD 回退本地引擎并 Toast 提示。
- **超时与限流**：`AbortController` 22 秒超时；`temperature 0.9`、`max_tokens 400`。

### 3.2 本地规则引擎（离线兜底，`generator.js`）

规则化生成，**不依赖网络与大模型**：

1. **词库分层**（每位诗人独立）：`open` 2 字意象起手 / `collo` 4 字短语 / `act` 2 字动作 / `ends` 3 字韵脚（按中华新韵分组）。
2. **句式拼装**：五言 = `2 + 3`；七言 = `4 + 3`；命中用户词时改为 `2 + 2 + 3`，把用户原词直接嵌进诗中。拼装后有字数守卫，确保格律字数正确。
3. **押韵**：随机取一个韵组，偶数句（第 2、4 句）同韵，首句 55% 概率入韵；末字取该韵组内的 3 字韵脚。
4. **关键词提取**：先在用户文本里做 2–4 字整词命中（命中则优先入诗），再退回单字 → 意象词映射（`IMG_MAP`，覆盖月/雨/花/雪/剑/舟/雁/柳/琴/灯/梦… 约 60 个常用字）。
5. **题名与题记**：按诗人各自的题名模板（`《{w}行》《{w}吟》…`）生成，题记记录用户原话与所用风格。

> 两种引擎返回同一结构 `{title, author, dynasty, lines[4], preface, comment, meta}`，HUD 不感知差异；生成结果会在「创作参数」行标注来源（大模型赋就 · 服务商 / 新韵 · X 韵）。

## 四、核心代码结构

```
poem-ink/
├─ index.html              入口：DOM 骨架 + 四个面板 + 脚本装载顺序
├─ start.bat               一键启动（起服务 + 开浏览器）
├─ server.ps1              纯 PowerShell 静态服务器（无 Node/Python 依赖）
├─ css/style.css           水墨主题：CSS 变量、四大面板、竖排诗文、徽章卡、弹层
├─ vendor/phaser.min.js    Phaser 3.80（本地化，离线可用）
├─ assets/                 背景 · 5 张诗人立绘 · 5 枚徽章
└─ js/
   ├─ data/
   │   ├─ poets.js         5 位诗魂：生平、非遗徽章锚点、风格词库、对谈台词 + IMG_MAP
   │   ├─ poems.js         诗词库（80 首名篇，含作者/朝代/体裁/题材标签）+ 8 个题材分类
   │   └─ badges.js        5 枚徽章：工艺、取用元素、配色、缘起、诗人原句
   ├─ systems/
   │   ├─ store.js         唯一状态源 + localStorage 存档 + 订阅通知
   │   ├─ audio.js         五声音阶程序化古琴配乐与音效（correct/wrong/reward/click）
   │   ├─ generator.js     赋诗引擎 · 本地规则（见 3.2）
   │   ├─ llm.js           赋诗引擎 · 大模型接入层（见 3.1）
   │   └─ quiz.js          闯关题库生成器（三种题型）
   ├─ ui/hud.js            DOM 交互层：标签页、诗人选择、赋诗、闯关状态机、徽章兑换、弹层、Toast
   ├─ game.js              Phaser 氛围场景（落花/流云/飞鸟/墨点/墨花），透明画布
   └─ main.js              启动入口：HUD.init() → Ambient.start()
```

**分层约定（来自 game-studio 插件规范）**

- 玩法状态全部在 `systems/`（`Store` 为唯一真相源），HUD 只做读写与渲染，Phaser 场景只做氛围，不承载规则。
- 场景层与 HUD 通过 `window.Ambient.ink()` 单向通信；`#scene-root` 设 `pointer-events:none`，不抢交互。
- 数据与渲染解耦：`poems/badges/poets` 均为纯数据，加内容不改逻辑。

### 5.3 可替换 / 可扩充的素材（含需要你提供的部分）

| 需求 | 规格建议 | 落位方式 |
| --- | --- | --- |
| **真实背景音乐** | `.mp3`/`.ogg`，古琴或箫，60–120s 可循环 | 放进 `assets/audio/`，在 `js/systems/audio.js` 用 `<audio>` 或 `decodeAudioData` 替换合成器 |
| **音效** | 点击 / 答对 / 答错 / 兑换 各 1 条 | 同上，挂到 `Music.correct/wrong/reward/click` |
| 更多诗人立绘 | 1680×2240，宣纸底或去背 PNG | 放 `assets/`，在 `js/data/poets.js` 追加一条（复制现有结构改词库即可） |
| 角色行走/待机序列帧 | PNG 序列，如 `npc-libai-idle-01..08.png` | 用插件 `sprite-pipeline` 归一化后，在 `game.js` 里 `load.spritesheet` + `anims` 播放 |
| 徽章动效 | 序列帧或 Lottie | 替换 `.badge-art` 内的 `<img>` |
| 可商用中文字体 | 楷体/宋体 `.woff2` | 放 `assets/fonts/`，用 `@font-face` 覆盖 CSS 变量 `--serif / --song` |

> 若你提供真实 BGM 与音效，我会把 `audio.js` 的合成器替换为音频文件播放器；若提供序列帧，我会把立绘升级为 Phaser 精灵动画（呼吸 + 衣袂摆动）。

## 六、已知限制与可扩展点

- 诗词库现收录 80 首名篇，可继续向 `js/data/poems.js` 追加，闯关题库会自动扩充。
- 赋诗已支持大模型（见 3.1）；未配置时退回本地规则引擎，**语义不保证通顺**，重在演示机制。
- 大模型由浏览器直连官方接口，API Key 仅存本机 localStorage；若双击 `index.html` 遇跨域限制，请改用 `start.bat`（localhost 源）。
- 徽章图为 AI 生成，已裁去右下角水印；如需更“重工”，建议后续用 SVG/3D 或实拍工艺图替换。
- 存档在 `localStorage`，清缓存会丢失；HUD 右侧 `↺` 可手动重置。
